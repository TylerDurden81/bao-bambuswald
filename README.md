# Bao im Bambuswald

Endless Runner im Browser: Panda Bao rennt durch den Bambuswald, sammelt Blätter, springt über Speere, stampft Panther platt und besiegt in jedem Level den Löwen.

Steuerung: Leertaste oder Tippen = Springen, gedrückt halten = Supersprung. Läuft am Desktop und am Handy.

Grafiken, Musik und Soundeffekte wurden mit Higgsfield generiert.
